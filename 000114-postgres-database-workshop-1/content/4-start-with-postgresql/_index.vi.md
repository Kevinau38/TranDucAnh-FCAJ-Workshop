#### Tổng quan

Trong chương này, bạn học các kiến thức cơ bản của PostgreSQL trên `rdspg-lab-db` với pgAdmin 4 và `psql`:

| Chủ đề | Bạn sẽ làm |
|---|---|
| Database và schema | Tạo `first_database` và `first_schema` |
| Table và kiểu dữ liệu | Tạo `first_table` và tìm hiểu các kiểu dữ liệu thường dùng |
| DML cơ bản | Thêm và truy vấn dữ liệu trong Query Tool |
| Role và user | Tạo role, user và kiểm tra quyền |
| Catalog và data dictionary | Truy vấn `pg_catalog` và `information_schema` |
| Session parameter | Thay đổi `search_path` cho một session |
| Truy vấn dữ liệu | Thực hành lọc, sắp xếp và giới hạn số dòng |
