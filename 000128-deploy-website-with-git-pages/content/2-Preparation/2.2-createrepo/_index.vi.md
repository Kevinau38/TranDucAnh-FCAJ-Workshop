Tạo ba repository **public**, mỗi repository cho một cách triển khai.

1. Đăng nhập [GitHub](https://github.com), chọn **+**, rồi **New repository**.
2. Với repository thứ nhất:
   - **Repository name**: `<username>.github.io`, trong đó `<username>` là username GitHub của bạn. Tên phải khớp chính xác, nếu không GitHub sẽ coi đây là project site.
   - **Description**: không bắt buộc, ví dụ `User site for the GitHub Pages workshop`.
   - **Choose visibility**: **Public**.
   - Để tắt **Add README**, **.gitignore** và **license** để repository trống.
   - Chọn **Create repository**.

![Tạo repository cho user site](/images/2-Preparation/2.2-new-repo.png)

3. Làm tương tự để tạo thêm hai repository public, trống, tên `workshop1` và `workshop2`.
4. Mở **Your repositories** và kiểm tra cả ba repository đã có trong danh sách.

![Ba repository](/images/2-Preparation/2.2-repo-list.png)

{{% notice info %}}
GitHub Pages miễn phí với repository public. Repository private cần gói trả phí mới dùng được Pages.
{{% /notice %}}
