Create three **public** repositories, one for each way of deploying.

1. Sign in to [GitHub](https://github.com), choose **+**, then **New repository**.
2. For the first repository:
   - **Repository name**: `<username>.github.io`, where `<username>` is your GitHub username. The name must match exactly, otherwise GitHub treats it as a project site.
   - **Description**: optional, for example `User site for the GitHub Pages workshop`.
   - **Choose visibility**: **Public**.
   - Leave **Add README**, **.gitignore** and **license** off, so the repository is empty.
   - Choose **Create repository**.

![Create the user site repository](/images/2-Preparation/2.2-new-repo.png)

3. Repeat for two more public, empty repositories named `workshop1` and `workshop2`.
4. Open **Your repositories** and check that the three repositories are listed.

![Three repositories](/images/2-Preparation/2.2-repo-list.png)

{{% notice info %}}
GitHub Pages is free for public repositories. A private repository needs a paid plan to use Pages.
{{% /notice %}}
