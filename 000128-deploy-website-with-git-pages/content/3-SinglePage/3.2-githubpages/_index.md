For a repository named `<username>.github.io`, GitHub turns on Pages automatically when the first commit arrives on `main`.

1. In the repository, choose **Settings**, then **Pages**.
2. Check that **Source** is **Deploy from a branch** (1), and that **Branch** is **main** and **/ (root)** (2). If it is not, select these values and choose **Save**.
