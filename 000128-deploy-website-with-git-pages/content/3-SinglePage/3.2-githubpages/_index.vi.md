Với repository tên `<username>.github.io`, GitHub tự bật Pages khi commit đầu tiên được đẩy lên `main`.

1. Trong repository, chọn **Settings**, rồi **Pages**.
2. Kiểm tra **Source** là **Deploy from a branch** (1), và **Branch** là **main** với **/ (root)** (2). Nếu chưa đúng, chọn các giá trị này rồi chọn **Save**.
