Project site nằm dưới một đường dẫn của user site, ở đây là `https://<username>.github.io/workshop1/`. Bạn có thể có nhiều project site, mỗi repository một site. Trong phần này, bạn vẫn push các file đã build, nhưng lần này một workflow **GitHub Actions** sẽ deploy chúng.
