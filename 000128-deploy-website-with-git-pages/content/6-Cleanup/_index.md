GitHub Pages is free, but if you do not need the three sites any more, delete the repositories. Deleting a repository also takes its site offline.

1. Open the repository, choose **Settings**, scroll to **Danger Zone** and choose **Delete this repository** (1).

![Danger Zone](/images/6-Cleanup/6-danger-zone.png)

2. Choose **I want to delete this repository** (1), read the warnings, type the full repository name when GitHub asks for it, and confirm.

![Delete the repository](/images/6-Cleanup/6-delete-dialog.png)

3. Repeat for `workshop1`, `workshop2` and `<username>.github.io`.
4. On your computer, delete the `quickstart`, `workshop1` and `<username>.github.io` folders.

{{% notice warning %}}
Deleting a repository cannot be undone. Check the name in the dialog before you confirm.
{{% /notice %}}
