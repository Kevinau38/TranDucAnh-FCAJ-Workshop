GitHub Pages miễn phí, nhưng nếu không cần ba website này nữa, hãy xoá các repository. Xoá repository cũng sẽ gỡ website tương ứng.

1. Mở repository, chọn **Settings**, cuộn xuống **Danger Zone** và chọn **Delete this repository** (1).

![Danger Zone](/images/6-Cleanup/6-danger-zone.png)

2. Chọn **I want to delete this repository** (1), đọc các cảnh báo, nhập đầy đủ tên repository khi GitHub yêu cầu, rồi xác nhận.

![Xoá repository](/images/6-Cleanup/6-delete-dialog.png)

3. Làm tương tự với `workshop1`, `workshop2` và `<username>.github.io`.
4. Trên máy tính, xoá các thư mục `quickstart`, `workshop1` và `<username>.github.io`.

{{% notice warning %}}
Xoá repository không thể hoàn tác. Hãy kiểm tra tên trong hộp thoại trước khi xác nhận.
{{% /notice %}}
