In this part you upload data to the lab bucket in different ways and compare the time each method takes. All commands run in the Session Manager terminal of `FCJ-StoragePerf-Instance`, and use the `$bucket` variable.

Each command starts with `time`. When it finishes, look at the `real` line: it is the elapsed time.
