#### Overview

In this chapter, you learn the basics of PostgreSQL on `rdspg-lab-db` with pgAdmin 4 and `psql`:

| Topic | What you do |
|---|---|
| Databases and schemas | Create `first_database` and `first_schema` |
| Tables and data types | Create `first_table` and review common data types |
| Basic DML | Insert and query data in the Query Tool |
| Roles and users | Create a role and a user, and test their privileges |
| Catalog and data dictionary | Query `pg_catalog` and `information_schema` |
| Session parameters | Change `search_path` for a session |
| Querying data | Practice filtering, sorting, and limiting rows |
