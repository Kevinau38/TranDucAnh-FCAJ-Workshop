`Chat-Proxy` làm mọi việc trong một function: tự kiểm tra path và HTTP method. Trong phần này bạn thay nó bằng mỗi method của API một function nhỏ, mô tả API bằng các resource thật, và để API Gateway sinh JavaScript client cho website.
